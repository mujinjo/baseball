# 투타 대전 야구

투수 vs 타자 1:1 대전 웹 게임 (이후 Capacitor로 모바일 이식). 기획·로드맵은 [PLAN.md](PLAN.md) 참고.

## 구조
- `packages/core` — 순수 TypeScript 규칙 엔진 (카운트/아웃/이닝/점수, 타구 기반 자동 주루). UI 의존 없음
- `apps/web` — Vite + Phaser 3 클라이언트 (M3: 포수 시점 2인 핫시트 대전 화면)

## 명령어
```
npm install
npm run dev        # 개발 서버
npm test           # core 단위 테스트
npm run typecheck
npm run build
npm run simulate -w @baseball/core   # 밸런스 시뮬레이션 리포트
```

## 자동 주루
주루 조작은 없다. `core/src/autoRun.ts`가 타구(종류×질)와 주자/아웃 상황으로 결과를 판정하고,
확률은 `core/src/autoRun.json`에서 조정한다.

## 투구 판정 (M2)
`core/src/pitch.ts`의 `resolvePitch(투구, 타자행동, 투수능력, 타자능력, rng)`가 한 투구를 `PitchEvent`로 바꾼다.
- 투수: 구종 + 노리는 위치(존 중심 (0,0), 경계 ±1) + 제구 게이지 → 실제 위치 = 목표 + 오차
- 타자: 스윙 여부 + 타이밍 오차(ms) + 선택적 구종/코스 예측 (맞추면 유리, 틀리면 불리)
- 결과: 볼/스트라이크/헛스윙/파울/인플레이(타구 종류·질) → M1 상태머신에 입력
- 수치는 `pitch.json`에서 조정하고 `npm run simulate`로 타율·삼진율·볼넷율을 확인한다

## 플레이 방법 (컴퓨터 대전)
- 타이틀에서 컴퓨터 난이도(쉬움/보통/어려움)와 내 팀(선공/후공), 이닝 수를 고른다
- **내가 투수일 때**: 구종을 고르고 코스(5×5 격자, 안쪽 9칸이 스트라이크)를 터치하면 바로 제구 게이지가 움직인다. 가운데에서 `정지!`(또는 스페이스바)
- **내가 타자일 때**: 컴퓨터가 던진 공이 날아오는 걸 보고, 공이 홈플레이트에 닿기 직전에 화면을 터치(또는 스페이스바)해 스윙. 터치하면 배트가 돌기 시작해 약 0.12초 뒤 타격 위치를 지나고, 그 시점이 공 도착과 얼마나 맞는지로 판정한다. 안 누르면 스윙 안 함
- 결과·주루는 core가 자동 판정한다
- 공을 맞히면(파울 포함) 위에서 본 구장에서 타구가 날아가고 비거리(m)가 표시된다. 홈런은 방향별 펜스(센터 120m, 파울라인 98m)를 넘는 거리로 나온다

## 장면 구성 (3D, 타자 뒤 낮은 시점의 야간 구장)
- **three.js**로 구장·선수·공을 3D로 그리고, **Phaser**는 투명 캔버스로 그 위에 UI(스코어보드, 버튼, 존 격자, 타구 화면)를 그린다 (`apps/web/src/main.ts`에서 두 캔버스를 겹침)
- 카메라는 홈플레이트 3.2m 뒤, 높이 1.1m에서 투수를 바라본다. `apps/web/src/three/stage.ts`의 카메라는 `game/geometry.ts`의 2D 투영과 같은 값이라 존 오버레이가 3D 장면과 어긋나지 않는다(테스트로 검증)
- `three/humanoid.ts`: 관절 위치로 자세를 표현하는 사람 모형 + 두 뼈 IK(팔꿈치·무릎)
- `three/rigs.ts`: 우타자(스탠스 → 타격 → 마무리, 위에서 볼 때 반시계. 왼손이 노브 쪽, 오른손이 위쪽을 잡음), 우완 투수(세트 → 다리 들기 → 스트라이드 → 팔 코킹 → 머리 위로 오버핸드 릴리스 → 팔로스루. 던지는 팔은 화면 왼쪽), 야수
- `three/world.ts`: 야간 구장(홈플레이트·타석 박스·마운드·파울 라인·베이스·펜스·관중석·전광판·조명탑·스카이라인). 실제 구장 치수 그대로라 파울 라인은 홈에서 바깥으로 벌어지고, 1루·3루와 1루수·3루수는 이 카메라 시야 밖이다(2루·유격수·2루수는 보임)
- 개발 서버(`npm run dev`)에서는 `window.__game`으로 장면에 접근해 자세를 확인할 수 있다 (`scene.stage.batter.poseAtProgress`)

## 컴퓨터 AI (`core/src/ai.ts`)
- 투수: 볼카운트를 읽어 존 안/유인구 비율을 조절하고, 직전 구종·코스와 겹치지 않게 섞는다. 난이도는 제구 게이지 정확도에 반영
- 타자: 눈으로 본 위치(오차)로 스윙 여부를 정하고 난이도별 타이밍 오차로 친다
- 1:1 대전은 같은 `resolvePitch`/`applyPitch`를 쓰고 AI 자리에 사람 입력을 넣으면 된다
